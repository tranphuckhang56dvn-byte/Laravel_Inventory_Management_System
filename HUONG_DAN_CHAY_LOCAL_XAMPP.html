HÌNH 1: SƠ ĐỒ LUỒNG HOẠT ĐỘNG KHỞI CHẠY HỆ THỐNG TRÊN LOCAL (XAMPP) Architectural Workflow
1 Khởi động dịch vụ trên XAMPP Control Panel
  1. Mở ứng dụng XAMPP Control Panel tại đường dẫn C:\xampp\xampp-control.exe.
  2. Bấm nút Start tại dòng Apache (đảm bảo hiện Port 80, 443).
  3. Bấm nút Start tại dòng MySQL (đảm bảo hiện Port 3306).

2 Quản lý Cơ sở dữ liệu MySQL trên phpMyAdmin & Nạp dữ liệu mẫu

1. Truy cập phpMyAdmin: Mở trình duyệt web truy cập địa chỉ http://localhost/phpmyadmin.

2. Cơ sở dữ liệu laravel_inventory_management_system: Đã được khởi tạo đầy đủ 18 bảng dữ liệu quan hệ và nạp dữ liệu mẫu (Users, Sản phẩm, Danh mục, Phiếu nhập, Phiếu xuất, Nhật ký kho).

3. Lệnh nạp lại dữ liệu mẫu (Clean State): Nếu muốn làm mới toàn bộ dữ liệu về trạng thái ban đầu, chạy lệnh sau trong Terminal:

$env:Path = "C:\xampp\php;C:\Program Files\Git\cmd;" + $env:Path
# Khởi tạo lại toàn bộ bảng và nạp Seeder

5 Xử lý sự cố thường gặp (Troubleshooting)
Lỗi 1: Cổng 80 hoặc cổng 3306 bị chiếm dụng (Port Conflict)
- Nếu Apache bị xung đột cổng 80: Sử dụng công cụ chạy nhanh chay_local.bat (khởi động máy chủ PHP độc lập tại cổng 8000, không phụ thuộc cổng 80 của Apache).
- Nếu MySQL không bật được: Đảm bảo không có dịch vụ MySQL/MariaDB khác đang chạy ngầm trên máy. Mở XAMPP Control Panel bấm Start cho MySQL.
Lỗi 2: Kiểm tra cấu hình kết nối MySQL trong file .env
File .env đã được thiết lập chuẩn kết nối phpMyAdmin: DB_CONNECTION=mysql, DB_HOST=127.0.0.1, DB_PORT=3306, DB_DATABASE=laravel_inventory_management_system, DB_USERNAME=root, DB_PASSWORD=. Truy cập phpMyAdmin tại http://localhost/phpmyadmin để xem trực quan dữ liệu.
